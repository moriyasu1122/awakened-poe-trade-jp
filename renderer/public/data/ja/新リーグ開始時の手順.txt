新リーグ開始時(本家の更新取り込み)の手順  ※2026/11 3.30対応時に更新

1. 本家の更新を取り込む
   git fetch upstream
   git merge upstream/master
   (衝突したら、日本語版の変更 = 'ja' の追加など を残しつつ本家側に合わせる)

2. ゲームデータを最新にする(poe_dat_export フォルダで)
   config.json の "patch" を最新のパッチ番号に書き換える
   npx pathofexile-dat

3. 日本語データを作り直す(renderer フォルダで)
   node build-ja-items.mjs   … アイテム名。既存の訳を残し、新アイテムはゲームデータから訳を取る
   node build-ja-stats.mjs   … Mod。build-ja-stats.mjs の TRANSLATIONS 辞書から作る

4. client_strings.js の項目の抜けを確認する
   本家の en/client_strings.js に増えた項目を ja/client_strings.js にも追加する
   (日本語訳は poe_dat_export/tables/Japanese/ClientStrings.json から探せる)

5. 動作確認と exe 作成
   yarn dev で確認 → build_exe.bat
   ※ 検索インデックス(*.index.bin)は yarn dev / yarn build 時に自動で作られる
     (以前の yarn make-index-files は不要になった)

メモ
- 本家の更新で英文の大文字/小文字だけが変わった場合は、build-ja-stats.mjs が自動で吸収する
- 英文自体が変わったModは辞書を直す必要がある。ゲームで NOT RECOGNIZED になったものから順に対応する
- 1つの英文に複数の日本語表記を登録したい場合は ['旧表記', '新表記'] のように配列で書く
