Awakened PoE Trade 日本語化パッチツール
========================================

このツール(apply_ja_patch.bat)は、公式配布版の Awakened PoE Trade(まだ日本語化されていないもの)に対して、
このフォルダで作成した日本語翻訳データだけを後から適用するためのものです。

【使い方(3通り、簡単な順)】

方法1: そのままダブルクリック
  インストール先が標準的な場所(Program Files など)であれば、
  apply_ja_patch.bat をダブルクリックするだけで自動検出してパッチが当たります。

方法2: ドラッグ&ドロップ
  パッチを当てたい Awakened PoE Trade のフォルダ(resources フォルダがある場所)を、
  apply_ja_patch.bat のアイコンの上にドラッグ&ドロップします。

方法3: 手動でパスを指定
  自動検出できなかった場合、実行すると入力を求められるので、
  対象フォルダのパスを入力(またはウィンドウにドラッグ)して Enter を押します。
  もしくはコマンドプロンプトから直接:

     apply_ja_patch.bat "C:\Program Files\Awakened PoE Trade"

「完了しました」と表示されたら、対象アプリを起動して日本語化されているか確認してください。

【注意点】

・このツールは main フォルダの node_modules(asarツール)と、renderer\public\data\ja の
  翻訳データを使うので、このプロジェクトのフォルダごと保持しておく必要があります。
・実行すると、対象フォルダの resources フォルダ内に元のファイルが
  「app.asar.original-backup」として自動的にバックアップされます。
  元の英語版に戻したい場合は、このファイルを app.asar にリネームし直してください。
・build-ja-stats.mjs で翻訳を追加・修正した後は、
  renderer フォルダで「node build-ja-stats.mjs」→「yarn make-index-files」を
  実行してから、このパッチツールを使ってください
  (renderer\public\data\ja の中身がそのまま使われるため)。
・新しいリーグでアプリ本体(en側のデータ)が更新された場合は、このパッチではなく
  最初に説明した「ソースを更新して build し直す」方法が必要です
  (このパッチは日本語データだけを差し替えるものなので、本体の更新には対応できません)。
